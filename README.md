SETUP INSTRUCTIONS

- Download Both Server and Client
- Open Server .sln file
- Go to MDIParent1.vb and search "change ip"
- Open Client .sln file
- Go to TeacherBroadcast.vb and search "change ip"
- Go to Form1.vb and search "change ip"
- Open Server .sln file and run, then enter
- Allow permissions
- Open Client .sln file and run
- Allow permissions

HOW TO USE
- Add your clients computer ip address
- Wait for the client to connect
- Once connected, select the clients IP address on the top-left side
- Press your desired button
